# Periodic-Table
This periodic table contains filters (category, phase at room temperature, radioactivity, origin, and discovery), sorts (category, phase, electronegativity, density, and discovery), and multiple statistics for each element. Statistics include:            
∙ Symbol, Name, Atomic Number, and Atomic Mass at front                        
∙ Numbers of electrons in each shell with a model in the back                        
∙ Electron Configuration and Affinity                        
∙ Electronegativity                        
∙ First Ionization Energy                        
∙ Density                        
∙ Melting and Boiling Points                        
∙ Discovery Year and Country(s)                        
∙ Atomic Radius                        
∙ Heats of Fusion and Vaporization                        
∙ Oxidation States
